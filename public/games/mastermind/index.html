Mastermind

Crack the hidden colour code using the clues after each guess, or set a code that stumps your opponent.

Mode
Level
Pegs

How to play
  • The code-maker hides a code of coloured pegs (the same colour can appear more than once). The code-breaker has a limited number of guesses.
  • After each guess you get clues: a black dot means one peg is the right colour in the right place, a white dot means a right colour in the wrong place.
  • The clues don't say which pegs they refer to. Use them to work out the code.
  • Break the code: the computer hides a code. Make the code: you hide one and watch the computer try. 2 players: pass the device. Online: play a friend, and swap roles on each rematch.
